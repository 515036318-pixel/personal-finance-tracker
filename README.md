# 个人记账预算管理工具

> 软件方法设计课程结课项目

## 项目简介

一个帮助个人管理日常收支、设置预算、查看统计报表的全栈 Web 应用。

## 技术栈

- 前端：React + Vite + Ant Design
- 后端：FastAPI + SQLAlchemy
- 数据库：SQLite
- 部署：Nginx + Uvicorn
